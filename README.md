# Jogos_de_Heranca
1f_trab01_estela_fiorentin

RELATÓRIO

1. Introdução

Este trabalho teve como objetivo aprender a publicar uma página web estática utilizando o GitHub Pages. Para isso, desenvolvi um site sobre o livro Jogos de Herança, utilizando HTML e CSS.
Escolhi esse tema porque tenho interesse em livros e queria desenvolver uma página com informações sobre uma obra que conheço.

2. Desenvolvimento

Primeiramente, organizei os arquivos do projeto, utilizando um arquivo "index.html" para estruturar o conteúdo da página e um arquivo "style.css" para definir a aparência do site.
No HTML, utilizei elementos como "header", "nav", "main", "section", "article" e "footer" para organizar as diferentes partes da página.
O site possui uma página inicial, uma sinopse, informações sobre os personagens, a família Hawthorne, os temas do livro e algumas curiosidades.

No CSS, defini cores, tamanhos, espaçamentos, fontes, bordas e outros elementos visuais. Também utilizei "display: grid" e "display: flex" para organizar os conteúdos e "@media" para deixar o site adaptável a telas menores.
Depois de finalizar a página, coloquei os arquivos em um repositório público no GitHub. Em seguida, utilizei o GitHub Pages para publicar o site.

3. Ferramentas utilizadas

Visual Studio Code

Utilizei o Visual Studio Code para escrever e editar os arquivos HTML e CSS.

Git

Utilizei o Git para versionar os arquivos do projeto e registrar as alterações realizadas durante o desenvolvimento.

GitHub

Utilizei o GitHub para armazenar o repositório do projeto e disponibilizar os arquivos na internet.

GitHub Pages

Utilizei o GitHub Pages para publicar o site como uma página web estática. A publicação foi configurada a partir do repositório do projeto.

4. O que aprendi

Durante o desenvolvimento, aprendi como organizar os arquivos de um site estático e como relacionar um arquivo HTML com uma folha de estilos CSS.
Também aprendi melhor como funciona o versionamento utilizando Git e como enviar alterações para um repositório no GitHub.

Outra aprendizagem importante foi entender o funcionamento do GitHub Pages. Descobri que é possível utilizar um repositório do GitHub como fonte para publicar uma página web acessível pela internet.
Além disso, aprendi sobre a importância de organizar os commits e de manter os arquivos do projeto em uma estrutura adequada para a publicação.

5. Dificuldades encontradas

Uma das dificuldades foi entender como os caminhos dos arquivos funcionam depois que o site é publicado. Foi necessário verificar o caminho utilizado para encontrar o arquivo CSS e organizar os arquivos no repositório.
Também precisei pesquisar como configurar o GitHub Pages e selecionar o branch e a pasta utilizados para a publicação.

6. Resultado

Ao final do trabalho, consegui publicar o site sobre Jogos de Herança utilizando HTML e CSS. O projeto ficou disponível publicamente por meio do GitHub Pages e o código ficou armazenado em um repositório público no GitHub.

7. Conclusão

O trabalho permitiu colocar em prática conhecimentos de HTML e CSS e aprender novos conceitos relacionados ao Git, GitHub e GitHub Pages. A experiência também mostrou como uma página criada localmente pode ser publicada e disponibilizada na internet.
